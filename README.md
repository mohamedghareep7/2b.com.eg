# 2B Egypt – Laptop Products Web Scraper

## Project Overview
This project is a Python web scraping application built to collect laptop product information from the 2B Egypt website.

The scraper uses Selenium to navigate the website, extract product information, and save the collected data into a CSV file.

## Target Website
https://2b.com.eg/en/computers/laptops.html

## Technologies Used
- Python
- Selenium
- XPath
- CSV

## Data Collected
The scraper extracts the following information:

- Product Name
- Current Price
- Old Price
- Discount Information
- Product URL
- Product Image URL

## Features
- Scrapes laptop products from multiple pages.
- Uses Selenium to interact with website content.
- Uses XPath to locate and extract product information.
- Exports the collected data into a CSV file.

## Output
The extracted product data is saved in a CSV file, which can be opened using Microsoft Excel or other spreadsheet applications.

## Project Purpose
This project demonstrates practical web scraping skills using Python and Selenium on a real e-commerce website.
